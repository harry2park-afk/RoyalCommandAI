# Royal Command Adaptive Consultation Room

Purpose: provide one reusable consultation-room framework that can adapt to the patient and the clinician without rebuilding the Room.

## Supported presence modes
- Live clinician video
- Clinician avatar
- Voice-only consultation
- Chat consultation

## Starting experience
New consultations start with the Standard Consultation Room unless a different accessibility need is known.

## Adaptive patient experience
After consultations begin, an authorised clinician can personalise the patient's room profile. Settings can include:
- Standard, child-friendly, senior-friendly, calm, minimal or custom room theme
- Live-video, avatar, voice-only or chat presence
- Large text
- Simplified controls
- Reduced visual load
- Avatar style
- Background style
- Clinician greeting

The patient may request a change in consultation style. The clinician remains able to choose an appropriate room configuration for the consultation.

## Design principle
The consultation method must adapt to the person. A patient should not be forced to use video when voice-only communication is more suitable, and a child or older person should not be forced into the same visual environment as a standard adult business user.

## Reuse
This framework is intentionally profession-neutral so the same Room system can later support psychology, counselling, legal consultations, accounting, health professionals and other approved human professional services.

## Future integrations
The data model is prepared for later connection to authenticated clinician profiles, appointment scheduling, live video, avatar services, consent controls, payment, receipts and eligible reimbursement/claiming workflows. Those integrations must be implemented separately and only when approved.
