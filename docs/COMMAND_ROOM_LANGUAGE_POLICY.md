# Command Room Language Policy

## Authoritative rule

The language selected by the customer in the Command Room language selector is the authoritative response language for that customer's Command Room.

- The selected language persists in the customer's account-backed UI preferences.
- It must not change automatically because the customer's prompt is written in another language.
- It remains active until the customer manually selects a different language.
- Every selected AI provider must answer in the selected language.
- Code, URLs, product names, proper nouns, and explicitly preserved source text may remain in their original form where appropriate.
- If no persistent language has ever been selected, the system may fall back to the language of the current question.
