# Royal Command Country Build Order — Phase 1

Status: Harry Park approved
Start: 2026-08-15 (Australia/Sydney)

## Mission
Build Royal Command country-by-country as one cooperating AI engineering team. One lead AI owns one country at a time, while all other AIs actively help with their strongest capabilities. Reuse the approved Royal Command base frame instead of rebuilding from scratch, then localise only what the country requires.

## Phase 1 assignments
- ChatGPT — Australia lead. Finish and stabilise the common/base application frame first. Continue helping every other country lead with architecture, integration, debugging, security and shared components.
- Gemini — United States lead.
- Claude — United Kingdom lead.
- Grok — Canada lead.

## Mandatory cooperation rule
The country lead is accountable for completion, but may request and use analysis, code review, research, debugging and implementation help from the other AIs. No AI should duplicate work another AI has already solved. Improvements that are generally useful must flow back into the shared base frame and then be reusable by every country implementation.

## Country build procedure
1. Start from the latest approved Royal Command base frame.
2. Copy/reuse the shared frame; do not fork the product into incompatible codebases.
3. Keep shared components in the common core and isolate country-specific configuration, legal text, language, payments, telephony, identity, tax/compliance and integrations.
4. Use a country-specific official Royal Command domain for the public country service. Before DNS/domain changes, verify that Royal Command controls the domain and that the intended DNS/hosting configuration is correct. Never invent ownership or overwrite an unrelated domain.
5. Preserve Harry Park approval gates for material production changes.
6. Preserve security boundaries: no secrets in source, no universal master credential, least-privilege service credentials, auditability and reversible deployments.
7. Test the country build before production release and report blockers clearly.

## Scale target
After the Phase 1 countries establish the reusable pattern, expand the same country-owner model toward approximately 100 countries. New country leads should inherit the latest approved shared frame, country checklist, security model and collaboration rules.

## Priority
Phase 1 priority is speed through reuse and cooperation, without sacrificing security, maintainability or the common Royal Command customer experience.
