## Implemented

- `src/lib/website-studio/v2`: versioned outcomes, read-only v1 decoding, readiness,
  tenant-scoped submission/idempotency, atomic Job+Outbox, staged host orchestration,
  fenced completion, global branch publication lock, ambiguous-publication recovery.
- `LocalFileStore`: real durable single-host development state. Never configure
  this adapter on Vercel's ephemeral filesystem. No lock stealing after crashes.
- `PostgresStore`: transactional shared-store adapter. Bootstrap SQL is supplied
  in `scripts/website-studio-private-store.sql` and has NOT been applied anywhere.
- `runner.ts`: pinned Sandbox SDK 3.3.0, pinned-image requirement, no egress,
  no host environment propagation, fixed build/test entrypoints, bounded duration,
  source revalidation, explicit nonpersistent cleanup. Cloud execution not yet run.
- `publication.ts`: checks tested source digest before credential lookup/mutation,
  `createCommitOnBranch(expectedHeadOid)`, checked returned tree, no force or retries.
- `preview.ts`: trusted immutable deployment identity, official automation header,
  redirect blocking, separate protection result; never calls HTTP 200 functionality.
- `examples/website-studio-test`: standalone EN/KO quote calculator fixture with one
  Core and Locale overlays; no RC/customer API or persistent customer data access.
