# RC 단계별 보강·복구·검증

Owner: Harry Park. 지시일: 2026-10-18. 최신 증거: [LATEST.json](LATEST.json).

기존 공통 코어와 고객 자료를 보존한다. 기존 승인은 필요한 조사·수정·시험·독립 검토·시험 브랜치 저장까지 이어진다. 실제 운영 승격, 통화 발신, 고객 발송, 결제·새 비용·데이터 이전은 이번 시험 범위에 포함하지 않는다. 새 화면·버튼·경로를 추가할 경우 AGENTS의 구체안 사전 승인 범위를 따른다.

| 순서 | 목표 | 상태 / 완료 조건 |
|---|---|---|
| 1 | 회사 전화 계정 접근 보호·검사 누락 방지 | 구형 2개 API를 기존 RC 소유자 권한으로 제한. 작업 브랜치 CI와 변경 범위 계산 보강. 로컬 검사·독립 검토 통과. 후속 검사 복구에서 기존 lint 15개 오류 해소, 원격 상태는 PR #863 확인. |
| 2 — 최우선 | 프로필 권한 보호 | 자기 프로필 UPDATE 정책·role 열 UPDATE 권한·비내부 트리거 없음 확인. 고객의 권한 변경을 차단하고 정상 프로필 편집·관리자 작업을 격리 DB에서 검증한 후 적용 계획 확정. 운영 DB 변경 미실행. |
| 3 | 자동 검사 복구 | 2026-10-18 완료: 기존 오류 15개 해소, 760개 테스트·브라우저 회귀 통과. 국가명 hydration 불일치도 최소 수리. [검증 기록](../verification/rc-quality-repair-20261018.md), 최종 원격 증거는 PR #863. |
| 4 | 고객 전체 이용 흐름 | 로그인 → 기존 폼·동의 → 방 생성 → 시험 결제/30일 이용권 → 교육·질문 → 재로그인. 기존 폼·URL을 확인한 구체안에 따라 연결. |
| 5 | 음성·전화 완결 | 고객별 소유권·허용 에이전트·이용권 검증. 소유자 발신 중복/예산 보호, 통화 기록 중복 방지·재생 검증. 실제 발신은 별도 승인된 수신 대상에 한정. |
| 6 | 문서 검색·답변 근거 | 원본 보존, PDF/OCR 추출, 관련 문서 검색·출처, 고객 격리, 수정·삭제 반영. 현재 최근 문서 전달을 RAG 완료로 표현하지 않음. |
| 7 | 전체 복구·운영 준비 | DB·저장 파일·R2·설정의 격리 복원. 계정별 접근·파일 열기·실기기 태블릿/음성 검사 후 기능별 운영 승격. |

추가 보강: AI 검토의 구조화된 판정·실패 차단, 답변 본문/방/모델에 결합된 실행 증명, 전용 서명 키, 측정에 기반한 성능 개선.
