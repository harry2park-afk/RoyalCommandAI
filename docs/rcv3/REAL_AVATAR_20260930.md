# Real video tutor connection — Preview

Owner scope: existing V4 education page, large realistic paid avatar, answers and unchanged-size typed chat underneath; desktop full-stage video and mobile upper-body crop. STANDARD, Codex Writer; independent review_avatar read-only Reviewer. Recovery tag recovery/rcv4-real-avatar-20260930 at c6bee738a384b9997d102855fa6504d0ebf11045. No forms, navigation, payment or Production changes. Existing work Preview branch remains the publication target.

Shared LearningAvatar and LearningAvatarPlayer provide LiveAvatar LITE transport. Existing RC curriculum, AI responses and speech endpoint stay authoritative: convert the returned audio to 24 kHz mono PCM16, send matching utterance IDs, and await the provider's corresponding completion. LiveKit supplies video and synchronized audio. Provider agent token and API key are never returned; only scoped WebRTC client credentials and an owner-bound signed cleanup receipt. No microphone/camera is published to LiveKit; existing RC microphone handling remains.

Server starts require the existing authenticated Preview session, an explicit owner allowlist and feature enablement, configured API key/avatar UUID and existing daily quota. Visiting the page only checks availability, never starts a paid session. Each avatar start consumes one existing chat quota slot in addition to existing speech calls. Stop, hidden page/device cancellation and unmount close sessions; provider maximum duration bounds failed cleanup. Idle playback releases after 30 seconds. Browser-local course bookmarks and customer records are unchanged.

Configuration (server-only Vercel Preview, never enter secrets in chat): LIVEAVATAR_API_KEY; LIVEAVATAR_AVATAR_ID (selected stock/custom avatar); RC_LEARNING_AVATAR_OWNER_IDS (comma-separated approved account UUIDs); RC_LEARNING_AVATAR_ENABLED=true. LIVEAVATAR_SANDBOX defaults to true (60-second provider sandbox cap); false allows a maximum 600-second test session, subject to purchased plan support. It does not purchase or renew a subscription. Stop works after starts are disabled. No environment values were changed in this work. Local configuration absent; deployed secret configuration cannot be confirmed through the available metadata tool. Real provider activation is pending account/setup verification.

Design limits: the provider's recorded appearance determines full-body/upper-body framing. CSS cannot create missing body footage. This integration does not implement free walking across textbook text or pointing at arbitrary paragraphs; LiveAvatar gesture direction during a live session is not supported by its published FAQ. No animated 3D substitute or fake speaking animation was shipped. While disconnected, the existing portrait is explicitly labelled as not connected. Phone upper-body framing must be checked against the chosen real avatar. The text chat retains its previous size and scrolls only its own history to the latest answer.

Validation: 31 focused tests cover quota/auth/origin gating, signed receipt ownership/expiry, provider error cleanup, PCM transfer and utterance completion, cancellation, idle release and existing voice/text/lesson behavior. TypeScript and production build checked in execution. Scoped changed transport/component lint passed; full LearningRoom lint still reports two pre-existing set-state-in-effect findings outside this modification. Independent review found and verified fixes for stale audio rejection and paid idle lifetime. Existing microphone/voice controls preserved. Provider video, lip sync and actual Galaxy/laptop audio are NOT verified.
