# RC V3 기본방·회원 이용·추가방 규칙

Harry 지시: 2026-09-23. 승인된 제품 규칙이며 구현 완료 증거가 아니다.
작업 범위: FAST, 문서만, 단일 작성자 Codex. Production/master 및 고객 데이터 변경 없음.

1. 신규 고객은 가입 과정의 기본방 생성 폼으로 본인 기본방을 만든 뒤 RC 회원 기능을 이용한다. 계정 인증만으로 기본방 생성이 완료됐다고 처리하지 않는다.
2. 기본방은 고객별 하나의 기준 방이다. 재시도·새로고침·다른 기기 접속으로 중복 생성하지 않는다. 기존 고객 기본방과 데이터는 보존하며 임의로 새 기본방으로 대체하지 않는다.
3. 기존 회원용 Create Room은 기본방이 있는 고객의 추가방 생성 전용이다. 이 화면에서 기본방을 다시 만들거나 추가방을 기본방으로 지정하지 않는다.
4. 기본방이 없는 고객이 추가방 생성 화면/API에 접근하면 기본방 가입 폼을 먼저 완료하도록 안내한다. 본인 기본방 존재 및 소유권은 서버에서도 확인하며 화면 표시만으로 제한하지 않는다.
5. 추가방 생성 화면과 기본방 이외의 모든 방에는 `← 실제 기본방 이름`을 표시한다. 클릭하면 해당 고객의 기본방으로 직접 이동한다. 고정 문구 `← 내 방`이나 다른 고객의 기본방을 연결하지 않는다.
6. 기본방과 다른 모든 방에 `내 방 목록`을 제공하여 본인이 실제 생성한 방을 선택하고 직접 이동할 수 있게 한다. 다른 방으로 이동할 때 기본방을 반드시 거치도록 강제하지 않는다. 기본방 복귀 링크와 방 간 직접 이동은 함께 제공한다. 미완성 초안은 생성된 방 목록과 구분하며 삭제·보관한 방은 사용 가능한 목록에서 제외한다.
7. 기본방 이름이 바뀌면 돌아가기 링크의 표시 이름도 동일하게 반영한다. 표시 이름과 실제 이동 대상 Room ID는 같은 고객의 기본방을 가리켜야 한다.
8. 폼 저장·유료방 결제 확인·방 생성·이용권 활성화는 기존 서버 검증을 유지한다. 이 규칙은 무료 기능에 새 결제를 요구하거나 가격을 결정하지 않는다.

공통 툴박스 재사용·고객 격리 규칙을 적용한다. 기존의 기본방 없는 RC 회원 이용을 허용하는 설명과 충돌하면 본 규칙을 따른다. 공개 외부 앱 바로가기는 RC 회원 기능 활성화가 아니다.

## 구현 검증 기준

- 기본방 없는 고객은 추가방을 생성할 수 없고 가입 폼으로 안내된다.
- 기본방이 있는 고객은 추가방만 생성할 수 있으며 기본방은 유지된다.
- 추가방 화면의 링크 이름 및 대상이 본인 기본방과 일치한다.
- 기본방뿐 아니라 다른 방에서도 `내 방 목록`으로 실제 생성된 방을 선택하여 직접 이동할 수 있다.
- 방 개수가 적거나 많아도 동일한 이동 방식을 사용하며 기본방 경유를 강제하지 않는다.
- 다른 고객의 방·초안·결제정보가 노출되지 않는다.

현재 상태: 규칙 기록 완료. 위 접근 제한·기본방 연결·목록 동작은 별도 구현 및 실제 검증이 필요하다.
