## 내용의 충실도

각 레슨은 배울 것 → 쉬운 설명 → 생활·업무 예시 → 직접 실습 → 이해 확인 → 요약 순서다. 묶은 원본의 모든 학습 목표와 실습을 포함하며 설명 중복만 줄인다. 기존 005번 이후 일부 본문은 매우 짧고 비슷한 실습 지시를 반복한다. 제목 병합만으로 완성이라고 하지 않고, 단계별 예시·좋은 답과 잘못된 답·검증 기준을 보강한다. 음성 튜터 설명으로 필수 교육 내용의 부재를 숨기지 않는다.

## 왼쪽 교육내용 · 오른쪽 AI 튜터

PC·태블릿 넓은 화면: 기존 LearningRoom을 수정한다. 왼쪽 약 60%에는 가입폼처럼 세로 한 열로 번호·제목·설명·실습 답변·확인 문제를 배치한다. 오른쪽 약 40%에는 튜터, 자막, 질문, 음성 제어를 둔다. 현재 설명하는 번호와 문단을 강조한다. 큰 새 박스나 새 가입폼은 만들지 않는다. 사용자가 이전 내용을 보고 있으면 강제로 스크롤하지 않는다.

휴대폰: 좁은 화면에서 두 열을 강요하지 않는다. 교육내용 한 열과 하단 고정 음성 제어를 사용하고 튜터는 작게 표시한다. 키보드가 답변·제출을 가리지 않아야 한다. 음성 질문을 글로 확인하고 수정할 수 있으며 타이핑도 유지한다.

튜터는 현재 번호·언어·승인된 수업내용을 기준으로 한 개념씩 설명하고 질문을 기다린다. 수강생이 말하는 동안 끼어들지 않는다. 사용자가 말하기를 시작하면 튜터 재생을 멈추고, 긴 침묵만으로 답변을 확정하지 않도록 발화 종료 조정과 명시적 전송을 제공한다. 음성 답은 초안으로 입력하고 고객 확인 후 기존 제출 경로로 평가한다. 음성만으로 수업 통과·결제·룸 생성·서비스 신청을 확정하지 않는다.

기존 아바타 자산을 우선 사용한다. 말하기·듣기·대기 상태는 실제 오디오 상태와 맞춰 표시한다. 자연스러운 입모양·실시간 영상 아바타는 별도 공급사 연결 및 비용 검증 전 완료로 표시하지 않는다.

## 음성과 휴대폰 요구사항

기존 src/app/api/rcv3/audio/route.ts에 음성 인식·읽어주기 코드가 있다. 현재 roomId 소유권과 유료 AI 서비스 이용권을 요구하므로 교육방에 그대로 붙이면 별도 방 이용권 때문에 막힐 수 있다. 인증 검사를 제거하지 않고 기존 음성 처리 공통 부분을 추출하여 교육 수강권·교육 사용량을 확인하는 어댑터와 연결한다. 새 재사용 기능은 기존 툴박스 등록·검증 후 화면에 사용한다. 현재 교육방 음성 어댑터는 아직 없다.

- 마이크 허용과 사용자 시작 동작 후 듣기·말하기를 활성화한다. 선택 교육 언어 ko/en/ja/zh/hi를 음성·자막에도 동일 적용한다.
- 녹음 → 인식 → 답변 → 읽어주기 흐름에 취소·시간 제한·중복 전송 방지를 둔다. 나가기/중지 시 녹음 트랙과 재생을 종료한다.
- 긴 수업은 문단별 재생과 이어듣기로 구성한다. 네트워크 실패 시 제출 초안을 유지하고 재시도한다. 원음은 기본 영구 보관하지 않는다.
- 유선·블루투스 이어폰은 기기의 선택된 출력 경로를 사용한다. 연결 해제 때 자동으로 큰 스피커 소리가 나오지 않도록 가능한 장치 변경 감지 및 재생 중지 처리를 시험한다.
- 휴대폰을 귀에 댔을 때 전화 수화부로 들리는지, 화면이 꺼져도 계속되는지는 웹에서 일괄 보장하지 않는다. Galaxy 휴대폰·Tab S11 Ultra·iPhone에서 실제 확인하고 미지원 기기는 이어폰 사용을 안내한다. 수화부 강제가 필수이고 웹에서 안 되면 별도 네이티브 오디오 경로가 필요하다.
- 음성 사용 비용은 A$16.50 안에서 제공 가능한 시간을 실측한다. 기존 하루 30회 제한은 무제한 음성 이용을 뜻하지 않는다. 무제한·추가 비용 없음 문구를 임의로 넣지 않는다.

## 기존 진도·시험·수료증 보존 설계

기존 COURSE ai-literacy-100-v1과 원본 001–100 ID·저장 결과·문제를 보존하고, 위 60개 묶음은 별도 curriculumVersion으로 관리한다. 묶음 완료는 포함된 원본 요구사항이 모두 서버에서 통과했을 때만 인정한다. 40개 과제를 삭제하거나 단순히 100을 60으로 치환하지 않는다. 기존 학습자는 제출·수료증을 잃지 않고 묶음 단위 완료로 환산하며 미완료 하위 과제만 이어간다.

최종 시험은 기존 30문항·30분·70점 기준을 유지하되 모든 60개 묶음 완료를 서버에서 확인한다. 기존 원본 완료 조건과 동등한지 검사한다. 새 수료증에는 60레슨 구성 버전을 기록하고, 과거 발급 수료증은 덮어쓰지 않는다. 과정 개편을 짧은 기존 자료 묶기에 그치지 않도록 교육 내용 검토를 별도로 통과해야 한다.

## 구현 순서와 완료 기준

1. 이 구성표를 기준으로 각 레슨 본문·실습 보강, 5개 언어 적용. 원본 누락·중복 검사.
2. 기존 교육방에 묶음 표시·서버 진도·시험·수료증 버전을 연결. 기존 진도와 통과 증거 보존 검사.
3. 툴박스 음성 공통 기능과 교육 권한 어댑터를 등록·검증한 뒤 왼쪽 교재/오른쪽 튜터 배치.
4. PC·모바일에서 마이크 거부, 끊김, 긴 침묵, 취소, 이어폰 해제, 언어 변경, 새로고침 복원과 실제 듣기·말하기 시험.
5. 가격·무료 문구·수료증 안내 일치, 실제 제공 기능만 홍보하는지 확인 후 격리 Preview 배포. Production 및 다른 방은 변경하지 않는다.

현재 확인: 소스 100개와 60개 대응표, 원본 누락·중복 없음, 기존 음성 API의 이용권 제약. 미확인/미구현: 새 화면, 60개 실행 진도, 교육 음성 어댑터, 실물 기기 오디오, 본문 보강, 결제·GST 조건. 설계 문서만 저장했으며 고객 화면이 바뀌었다고 보고하지 않는다.
