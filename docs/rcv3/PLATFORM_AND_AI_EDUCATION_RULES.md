# RC V3 플랫폼 및 무료 AI 교육 규정

결정일: 2026-09-21 · Owner: Harry Park · 적용: RC V3 Preview 개발. Production/master 변경 권한으로 확대하지 않는다.

## 고객이 직접 쓰는 공통 플랫폼

1. RC V3는 공통 기본 프레임에 고객이 자기 방을 구성하는 방식이다. 고객별 별도 프로그램을 반복 제작하지 않는다.
2. Create Room의 쉬운 세로 폼에서 필요한 기능만 선택하고 선택 항목은 건너뛸 수 있게 한다. 기능 설명 끝에는 기존 Translate를 사용한다. 기존 AI Helper와 버튼 편집을 재사용한다.
3. 방 없이 외부 앱을 이용하는 고객은 기존 바로가기 메뉴를 통해 해당 앱으로 이동하여 자기 계정으로 로그인한다. 바로가기는 계정 연결이나 유료 이용권을 의미하지 않는다.
4. 타인의 방 방문은 소유자가 허가한 범위 안에서만 가능해야 한다. 인증, 소유권, 초대/철회와 데이터 격리를 서버에서 확인한다.
5. RC 자체 채팅과 외부 채팅 바로가기는 별개다. 기존 메뉴 목록을 재사용한다.
6. 툴방에서 추가·편집·제거하며 유료 툴도 결제 전에 배치할 수 있다. 서버 결제 확인 후 활성화하고, 미결제·만료·연결 실패 시 위치와 설정을 유지한다. 고객의 명시적 제거 전에는 자동으로 지우지 않는다. 구독 취소·방에서 제거·데이터 삭제는 구분한다.

툴 수명주기의 상세 기준은 [기존 툴방 설계](SELF_SERVICE_TOOL_ROOM_DESIGN.md)를 따른다. 위 규정은 목표이며 방문허가·RC채팅·모든 툴 자동연결이 이번 교육방 작업으로 완성되었다는 뜻이 아니다.

## 무료 AI 교육방

- 로그인한 고객에게 무료 교육 진입점을 제공한다. 교육만을 위해 유료 방 구매를 요구하지 않는다.
- 001–100번 과목, 하루 3–4과목의 30일 권장 계획. 진도와 완료 번호가 보이고 다시 이어서 배운다. 30일은 출석 강제 기간이 아니다.
- 001–050: 역사, 이론, 모델 원리, 현재 역량, 안전한 사용. 확인 문제로 이해를 점검한다.
- 051–100: 점차 어려운 실습. 회사 보고서, 표·KPI·데이터 해석, 발표 자료, 웹페이지, 코드·시험, 업무 자동화, 미래 시나리오와 최종 종합 프로젝트를 다룬다.
- AI는 설명·예시·반례·실습·수정 피드백을 제공한다. 결과물은 주제 적합성·완성도·검증·명확성 각25점으로 평가하여 70점 이상일 때 완료한다. AI가 코드 실행이나 실제 업무 성과를 검증했다고 가장하지 않는다.
- 학습자는 가상 회사 자료로 실습한다. 개인·고객 비밀 자료를 요구하지 않는다.
- 모든100과목 완료 후 전체 영역에서 뽑은30문항,30분 시험. 서버가 제한시간·정답·점수를 판단하며70점 이상이면 RC 수료증 발급. 새 시험 하루3회, 무료 AI 요청은 평가 포함 하루30회(UTC).
- 통과한 실습 증거는 후속 실패 제출로 덮어쓰지 않는다. 수료증은 소유자만 조회하며 계정 이름, 과정, 점수, 발급일, 고유번호를 표시한다.
- 수료증은 RC의 비공인·비감독 교육 이수 기록이다. 전문 자격·실무 능력·본인 작성 여부를 보증하지 않는다.
- 현재 AI 역량은 날짜가 있는 근거로 설명한다. 미래는 사실·추론·전망을 구분하며 예측을 확정 사실로 가르치지 않는다.
