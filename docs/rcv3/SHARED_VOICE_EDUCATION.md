# RC 공통 음성 교육방

## 한 번 만든 교육방을 모든 과목에 사용

과정별로 방 프로그램을 새로 만들지 않고, 검토한 교육과정 자료를 공통 엔진에 등록한다. 과정에는 고유번호·버전·이름·학습 대상·과목·수업번호·언어별 교재·학습 목표·근거 자료·튜터 설명 기준을 넣는다. 기타·음악·춤·요가·학교·대학 과정도 같은 규격을 사용한다. 실제 교재와 시범 자료가 준비된 과정만 공개한다.

## 수업과 대화

왼쪽 교재와 오른쪽 튜터가 같은 과정·수업번호를 참조한다. 음성 대화를 시작하면 질문 듣기 → 질문 전송 → 짧은 튜터 설명 → 다시 질문 듣기가 이어진다. 타이핑과 기존 듣기 버튼도 유지한다. 수업 변경·언어 변경·기기 연결 해제·종료 시 마이크와 재생을 정리한다.

현재 구현은 번갈아 대화하는 방식이다. 재생 중 말로 끼어들기와 잠금 화면 음성 대화는 지원하지 않는다. 이 기능은 실시간 양방향 음성 연결과 기기별 시험이 추가로 필요하다. 운전 중 사용 가능하다고 확정해 홍보하지 않는다.

## 진도·자료·이용권

과정·버전·회원·수업별 기록을 분리한다. 질문과 음성 답변 자체가 수료·결제·진도 완료를 확정하지 않는다. 시험과 실습은 서버에서 평가한다. 기존 AI 과정의 진도·시험·수료증을 유지하며 다른 과정은 전용 평가 기준과 저장 연결을 등록한 뒤 공개한다. 과목 이름만 넣고 완성된 교육이라고 표시하지 않는다.

교육은 결제 확인 후 30일 이용, 만료 시 잠금, 유료 재등록 후 재개라는 확정 설계를 따른다. 기본방 월회비는 별도다. 이 문서의 공통 음성 엔진 개발이 결제·만료 처리를 완성한 것은 아니다.

## 확장 방법

검토한 과정 자료를 coursePackSchema로 검사하고 catalog의 등록 목록에 추가한다. 공통 튜터는 등록된 과정과 수업만 읽으며 학생 요청으로 새 과정을 발행하지 않는다. 현재 등록은 기존 AI 과정 하나다. 수업 목록·진도·평가·수료증 화면의 완전한 다과정 전환은 후속 연결이 필요하다.

이번 연결: 과정 형식 검증, 등록된 교재 기반 공통 튜터, 공통 음성 순서 제어, 기존 AI 교육의 음성 대화 버튼. 실물 휴대폰에서의 인식·재생은 별도 확인 대상이다.
