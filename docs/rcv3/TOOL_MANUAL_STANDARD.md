# RC V3 Button Warehouse Manual Standard

Every button/tool stored in the RC V3 Toolbox must be a reusable registered tool, not an isolated visual button.

## Required stored manual
Each tool must store:
- Tool name and stable Tool ID
- Purpose / function
- How to use it
- Required account, permission, connection or entitlement
- Installation method
- Save/persistence rule
- Version
- Shared source path

A tool without these manual fields must fail registration and must not be offered in the Toolbox.

## Placement rule
1. Choose **Place** in Toolbox.
2. Toolbox closes.
3. A translucent shadow of the selected button follows the pointer with the pointer at its centre.
4. Click an empty location in the room to place it.
5. Existing occupied buttons cannot be placement targets.
6. Adjust with Edit Buttons when needed.
7. Save. The editor closes only after the server reads back and confirms the saved layout.

## Duplicate rule
A Room cannot install the same Tool ID twice. Existing tools display **In Room** and their Place action is disabled. Their Manual remains readable.

## Safety / portability
Tool reuse copies the registered function and portable UI settings only. It never copies another customer's data, credentials, conversations, account connections, entitlements or payment state.
