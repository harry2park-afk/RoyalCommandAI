## 튜터 행동

한 번에 짧은 설명과 하나의 행동만 제시한다. 예시 요청과 학습자가 실제로 얻은 결과를 구별한다. 고객이 직접 시도하면 좋은 점 하나·고칠 점 하나를 설명하고 재시도를 기다린다. 결과가 없으면 짧게 확인하고 성공을 추정하지 않는다. 음성/타이핑은 기존 경로를 사용한다. 가상 자료만 사용하며 실제 발송·결제·예약·계정 연결을 수업 성취로 요구하지 않는다.

일반 대화 피드백과 서버 평가를 구분한다. 현재 초기 원본은 기존 확인 문제, 후반 원본은 기존 제출 평가로 진도가 저장된다. 실습 증거 필수화, 자동 재생의 실습 지점 정지, 별도 실습 상태 저장은 이번 콘텐츠 변경에 포함되지 않는다. 기존 연속 읽기는 그대로이며 질문 대화에서 단계별 안내를 받는다.
