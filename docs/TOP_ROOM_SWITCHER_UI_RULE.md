# Top Room Switcher UI Rule

Owner-approved placement and behavior:

- Do not show a room button at the far top-left before the company name.
- `Royal Command AI` remains the company title at the left of the top header.
- Room shortcut buttons appear immediately to the right of `Royal Command AI`.
- The generic base room named `Command Room` is not shown as a shortcut.
- Show only configured customer room shortcuts, up to 12.
- Buttons shrink automatically as the visible room count grows.
- Until specialist rooms are created, show one temporary sample shortcut labelled `회계룸 샘플`; it routes to the current room only as a navigation prototype and must be removed automatically as soon as a real specialist room exists.
- Do not change the AI dock, language selector, sidebars, composer, speaker, microphone, Select All, SAVE, or DELETE while implementing this header shortcut row.
