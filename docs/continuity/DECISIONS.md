# RC 압축 결정사항

자료 범위: 이번 대화의 직접 요청, 이전 RC 대화 검색 요약, 현재 저장소. 이전 AI의 '완료' 발언은 현재 운영 증거로 승격하지 않았다. 전체 원문은 아니며 검색이 회수하지 못한 대화는 빠질 수 있다. 비프로젝트 개인정보와 외부 메일 원문은 제외했다.

## 유지할 핵심 결정

- 사업: 'AI 인터넷을 파는 회사'. 초기 핵심은 Legal / Accounting / Personal Assistant. 검증된 기본방을 고객이 복사·꾸미고 자기 계정과 기능을 연결해 유료로 사용한다. RC 본부는 계정·권한·사용량·결제·장애·업그레이드를 관리한다.
- 공통 RC Master/Core 하나를 유지한다. RCA는 호주 파생판이며 국가별 차이는 Country Profile/Pack/Adapter/Locale로 처리한다. 국가/고객마다 동일 엔진을 새로 만들지 않는다.
- 단일 HARRY RC PREVIEW / PR748에서 개발한다. 현재 작업 중심은 RC V3. Production/master는 별도 승인 없는 변경 금지. 일시적인 배포 URL을 사용자 작업 주소로 늘리지 않는다.
- 고객 데이터·인증·메모리·문서·전화번호·메일·Harry의 개인 시스템은 템플릿과 분리한다. 복사는 기능 정의를 재사용하는 것이지 소유권/인증 복제가 아니다. 기본 AI/메일/전화 기능은 제공하되 고객 자신의 연결을 검증해야 한다.
- RC V3는 이미지 배경 위의 기능 버튼 구조. 버튼을 배치/수정해 쓰고 같은 기능을 이식할 수 있어야 한다. 기존 기능 ID와 저장/연동을 살려 보완한다.
- Create Room: 룸 이름이 먼저, 사용 목적에 따라 질문 변경. 비서를 선택하면 본인 이메일/전화 등 필요한 항목 표시. 기본 항목은 단순하게, 추가 기능은 선택형으로 둔다.
- 월 이용료/약관/가입 조건/정기 결제 동의 → 결제 완료를 서버 확인 → 룸 생성. 법률 약관이나 가격을 AI가 임의 확정하지 않는다. 무료 룸 정책도 임의 추정하지 않는다. 현재 결제 미설정 상태를 강제로 열지 않는다.
- UI: 쉬운 영어 기본, Save/Cancel/Close 등의 익숙한 라벨은 영어 유지. 설명 끝 Translate는 가입/계정 언어로 이해를 돕는다. 모든 영역에서 쓸 공통 기능으로 만들되 미적용 구역까지 완료라고 하지 않는다.
- 9월20일 답변/음성 요구: 스피커 ON은 사용자가 OFF할 때까지 유지. 답변이 끝나도 OFF로 바꾸지 않음. 새 답변도 읽음. RC에서 바꾼 언어가 우선이고 선택이 없으면 가입 언어. 원문과 표시 언어/음성 표현은 구분한다.
- 마이크: 입력창의 마이크로 받아쓰기, 사용자가 수정하고 Send. 과거 자동 전송/대화 모드로 임의 복귀 금지. 음성/텍스트 요구의 변천은 최신 명시적 언어 요구를 따른다.
- 고객용 오피스: 사실적인 사무실 배경과 버튼/명패를 분리하고 노트북/휴대폰에서 사용. 레벨별 사무실 제작 요구가 존재하지만 현재 코드에 모든 레벨/반응형 시각 엔진이 완성됐다는 증거는 없다.
- Katie 기본 역할: 부재중 전화 메시지, 메일 정리·요약·답장 초안, 수입/지출/납부일, 일정/예약 준비, 영어 학습/읽기. 발송·외부 전화·예약 확정·삭제·결제/송금은 실행 승인 필요. 기능 범위 요구와 실제 연결 상태는 별도로 기록한다.

## 최신 정정

Harry는 기존 규칙을 이미 정리했으므로 중요하지 않은 규칙을 더 만들지 말라고 지시했다. 기억 문서는 작업 기록으로 유지하고 새로운 의무 시작/종료 절차는 철회했다. 기존 핵심 보호·재사용 원칙을 중복해서 새 규칙으로 만들지 않는다.

## 충돌 처리

새로운 명시적 사용자 지시와 현재 거버넌스가 우선한다. 오래된 문서/AI 보고는 증거 날짜를 붙인다. '신규 고객은 모두 Not Connected'라는 이전 표현과 '기본 AI를 제공'하는 후속 요구는 연결 의미를 구분한다: 플랫폼 제공 기본 서비스는 가능하지만 Harry 개인 인증을 복제할 수 없다. 실서비스 활성화는 현재 entitlement/연동 검증으로 판단한다.

이 기억은 새 배포/실결제/계정 연결에 대한 포괄적 승인이 아니다. 기존 승인 범위의 안전한 작업은 반복 확인 없이 이어가되, 별도 승인이나 소유자 인증이 실제 필요한 단계만 구체적으로 설명한다.
